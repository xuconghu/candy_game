## 🎛️ 功能模块

### 📊 仪表板
- **系统统计**: 显示用户数量、游戏记录、会话数量等关键指标
- **实时数据**: 点击"刷新数据"按钮获取最新统计信息
- **可视化展示**: 使用卡片式布局展示各项数据

### 👥 用户管理
- **用户列表**: 查看所有注册用户
- **搜索功能**: 按用户名或用户ID搜索
- **用户详情**: 点击"查看详情"查看用户完整信息
- **用户统计**: 查看单个用户的游戏统计数据

### 🎮 游戏记录
- **游戏历史**: 查看所有完成的游戏记录
- **搜索过滤**: 按游戏ID、用户ID或会话ID搜索
- **详细信息**: 查看每个游戏的完整数据

### 🔄 游戏会话
- **会话监控**: 查看所有游戏会话（活跃和已结束）
- **状态跟踪**: 区分活跃会话和已结束会话
- **会话详情**: 查看会话的完整信息

### 📝 游戏事件
- **事件日志**: 查看所有游戏事件记录
- **事件类型**: 显示不同类型的游戏事件
- **时间追踪**: 按时间顺序查看事件

## 📡 API端点

管理系统使用以下API端点：

### 系统API
- `GET /api/health` - 健康检查
- `GET /api/stats` - 系统统计信息

### 用户API
- `GET /api/users` - 获取所有用户
- `GET /api/users/{id}` - 获取用户详情
- `GET /api/users/{id}/stats` - 获取用户统计
- `GET /api/users/{id}/games` - 获取用户游戏记录

### 游戏API
- `GET /api/games` - 获取所有游戏记录
- `GET /api/sessions` - 获取所有游戏会话
- `GET /api/events` - 获取所有游戏事件

## 🛠️ 故障排除

### 常见问题

1. **无法加载数据**
   - 检查网络连接
   - 确认后端服务器正在运行
   - 点击"重试"按钮

2. **API错误**
   - 检查服务器状态：`http://106.15.184.68/api/health`
   - 查看浏览器控制台错误信息

3. **数据显示异常**
   - 刷新页面
   - 清除浏览器缓存

### 调试信息

打开浏览器开发者工具（F12）查看：
- **Console**: JavaScript错误和API响应
- **Network**: API请求状态和响应数据

## 📈 数据统计说明

### 统计指标
- **总用户数**: 注册用户总数
- **游戏记录**: 完成的游戏总数
- **游戏会话**: 创建的会话总数
- **活跃会话**: 当前正在进行的会话
- **游戏事件**: 记录的事件总数

### 数据更新
- 数据不会自动刷新
- 需要手动点击"刷新"按钮获取最新数据
- 建议定期刷新以获取准确信息
