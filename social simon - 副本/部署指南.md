### 方法二：手动部署

如果自动部署失败，可以手动执行以下步骤：

1. **连接到服务器**
   ```cmd
   ssh -i "C:\Users\ROG\Downloads\ecs-ssh-key.pem" ubuntu@106.15.184.68
   ```

2. **更新系统**
   ```bash
   sudo apt update
   ```

3. **安装Node.js**
   ```bash
   curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
   sudo apt-get install -y nodejs
   ```

4. **安装Nginx**
   ```bash
   sudo apt install -y nginx
   ```

5. **安装PM2**
   ```bash
   sudo npm install -g pm2
   ```

6. **创建项目目录**
   ```bash
   sudo mkdir -p /var/www/candy-game
   sudo chown -R $USER:$USER /var/www/candy-game
   ```

7. **部署文件**（需要先上传deploy_package到服务器）
   ```bash
   cp -r ~/deploy_package/frontend/* /var/www/candy-game/
   cp -r ~/deploy_package/backend /var/www/candy-game/
   ```

8. **配置Nginx**
   ```bash
   sudo tee /etc/nginx/sites-available/candy-game > /dev/null << 'EOF'
   server {
       listen 80;
       server_name _;
       
       location / {
           root /var/www/candy-game;
           index candy_game.html;
           try_files $uri $uri/ =404;
       }
       
       location /api/ {
           proxy_pass http://localhost:3000/api/;
           proxy_http_version 1.1;
           proxy_set_header Upgrade $http_upgrade;
           proxy_set_header Connection 'upgrade';
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           proxy_cache_bypass $http_upgrade;
       }
   }
   EOF
   ```

9. **启用站点**
   ```bash
   sudo ln -sf /etc/nginx/sites-available/candy-game /etc/nginx/sites-enabled/
   sudo rm -f /etc/nginx/sites-enabled/default
   sudo nginx -t
   sudo systemctl restart nginx
   sudo systemctl enable nginx
   ```

10. **启动后端服务**
    ```bash
    cd /var/www/candy-game/backend
    pm2 start simple-server.js --name candy-game-backend
    pm2 save
    pm2 startup
    ```

## 🔧 故障排除

### SSH连接问题
如果SSH连接失败：

1. **检查密钥权限**
   ```cmd
   icacls "C:\Users\ROG\Downloads\ecs-ssh-key.pem" /inheritance:r /grant:r "%USERNAME%:R"
   ```

2. **使用PuTTY连接**
   - 下载PuTTY和PuTTYgen
   - 用PuTTYgen转换.pem文件为.ppk格式
   - 使用PuTTY连接

3. **检查防火墙**
   确保本地防火墙允许SSH连接

### 服务器问题
如果部署后无法访问：

1. **检查服务状态**
   ```bash
   # 检查Nginx状态
   sudo systemctl status nginx
   
   # 检查后端服务状态
   pm2 status
   pm2 logs candy-game-backend
   ```

2. **检查端口**
   ```bash
   # 检查端口占用
   sudo netstat -tlnp | grep :80
   sudo netstat -tlnp | grep :3000
   ```

3. **检查防火墙**
   ```bash
   # Ubuntu防火墙
   sudo ufw status
   sudo ufw allow 80
   sudo ufw allow 22
   ```
